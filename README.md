# Ricardo Perello

MSc student in Cyber Security at ETH Zurich. Intern at [Dialectic](https://dialectic.com).

I work on public-coin arguments and proof systems in Rust.

## Selected work

**[Argus](https://github.com/ricardo-perello/argus)** — Rust interface for public-coin interactive arguments. Protocols are written as prover, verifier, and indexer roles against typed channels. One backend compiles the same program with Duplex-Sponge Fiat–Shamir; another runs it interactively.

**[RepliCode](https://github.com/ricardo-perello/RepliCode)** — Deterministic Wasmtime runtime with POSIX-like I/O, so the same program can execute in lockstep across replicated nodes.

**[arkworks-fuzz](https://github.com/ricardo-perello/arkworks-fuzz)** — Fuzzing campaigns against Arkworks field, curve, and serialization code.
